プライバシーポリシー

対象：リストメモ、買い物メモ（呼び出し名：おつかいメモ）、やることメモ
最終更新日：2026年10月27日

本アプリは、開発者本人の個人利用を目的として、AlexaからGoogle Tasksを操作するためのものです。

1. アクセスする情報

利用者が承認したGoogleアカウントのタスクリスト名・識別子、タスク名・識別子・完了状態などを取得します。また、Googleへの接続に必要なOAuth認証情報を使用します。Googleアカウントのパスワードを本アプリが取得・保存することはありません。

Alexaが認識した発話から、追加・確認・完了の操作と対象のタスク名を受け取ります。

2. 利用目的

取得した情報は、Google Tasksの対象リストを見つけること、タスクを追加・一覧表示・完了にすること、および結果を音声・画面で返すことに使用します。開発者はGoogleユーザーデータを販売、広告配信、AIモデルの学習のために利用しません。

3. データの送信と共有

本アプリはGoogle Tasks APIを通じてGoogleとデータを送受信します。Alexaの実行環境であるAmazon側でも、発話から得た操作内容、タスク名、応答内容などが処理されます。開発者は、これらの機能の提供に必要な処理を除き、Googleユーザーデータを他の第三者へ提供しません。

GoogleおよびAmazonによるサービス上の取り扱いは、それぞれのプライバシーポリシーや利用者の設定にも従います。

4. 保存と保護

タスク本体は利用者のGoogle Tasksに保存されます。接続用の認証情報はAlexaの実行環境内の設定として保存し、公開ウェブページや公開コードに掲載しません。処理に必要な接続情報などを実行中のメモリで一時的に保持する場合があります。

タスク名や応答内容は、Alexaの音声履歴、カード、画面表示などに含まれる場合があります。Amazonによる記録の保存・削除は、Alexaのプライバシー設定から管理できます。

5. 利用停止・アクセス権の取り消し

Googleアカウントの「サードパーティ製のアプリとサービスとの接続」で「alexa-list-memo」のアクセス権を取り消すと、本アプリからの接続を停止できます。Google Tasks内のタスクはGoogle Tasksから、Alexaの音声履歴はAlexaのプライバシー設定から管理・削除できます。

接続用の認証情報は、利用停止時に開発者が無効化し、スキルの設定から削除します。

6. Googleユーザーデータに関する方針

Google APIから受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

7. お問い合わせと改定

お問い合わせ先は、Googleの同意画面に表示されるユーザーサポートメールをご確認ください。データの取り扱いを変更する場合は、このページを更新します。
